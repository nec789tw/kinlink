繫族 KinLink ｜ 先看我（一般使用者，兩分鐘）
══════════════════════════════════════════════

1. 解壓縮，放在可以寫入的地方
   把這個 zip 解壓到隨身碟、桌面、「文件」或任何一個資料夾。
   （在 zip 上按右鍵 →「全部解壓縮」。不要直接在 zip 裡面點兩下 繫族.exe：
     那樣資料會存進 Windows 暫存區、之後可能被清掉，程式會跳出說明並拒絕開啟。）
   繫族不用安裝，不要放進 C:\Program Files。放在唯讀的隨身碟、或 SD 卡防寫開關打開時，
   程式會跳出中文說明：請把整個資料夾複製到隨身碟、桌面或「文件」再開。
   之後「這個資料夾」就是全部：程式、資料、備份都會放在這裡，
   要搬家就整個資料夾複製走。

2. 第一次雙擊 繫族.exe，Windows 可能跳出藍色視窗
   「Windows 已保護您的電腦」——這是因為程式沒有花錢買數位簽章，
   不是中毒。請按左邊小字「其他資訊」→ 再按「仍要執行」。
   只有第一次會問。若防毒軟體攔下，請把 繫族.exe 加入允許清單。

3. 開起來看到的是「虛構示範資料」
   畫面上方有提示條。要開始建自己的家族：
   ① 左下角「瀏覽模式」→ 輸入 PIN（預設 0000）→ 房頭選「全部（委員）」→ 解鎖
   ② 「設定」→「清空示範資料」
   ③ 「設定」→「下載匯入範本」，用 Excel 填族人資料（另存成 CSV UTF-8）→「匯入 CSV」
   ④ 「祭祖」→ 建活動；「列印」→ 印通知、名冊、穴排位圖
   詳細步驟在操作手冊：左邊選單最下面的「關於」→「開啟手冊」（單張 A4，可印出來貼牆上）。

4. 一定要做的三件事
   ・改 PIN：解鎖後到「設定」→「編輯鎖」→「設定／重設 PIN」，別留 0000，並抄在交接單上。
   ・用完上鎖：繫族不會自動上鎖。改完資料請按左下角「編輯中」（或上方的「完成，鎖定」）
     回到瀏覽模式，再離開電腦。
   ・備份：資料都在 繫族.exe 旁邊的 繫族.db（「設定」→「資料」可看到完整位置）；
     程式每次開啟、每次解鎖都會自動備份到旁邊的 backups 資料夾，
     「設定」→「立即備份」做的備份也存在那裡（檔名開頭是「繫族-備份-」）。
     但整個資料夾也請定期複製一份到別的地方（另一支隨身碟或電腦）。

5. 沒有畫面／開不起來？
   ・Windows 10/11 通常內建 WebView2；沒有的話程式會改用你的瀏覽器開啟，
     並跳出一個小視窗。用完請先關掉瀏覽器，再按小視窗的「確定」結束繫族；
     按「確定」之前不要拔隨身碟。
   ・仍有問題：到 GitHub 專案頁的 Issues 留言，附上作業系統版本。

6. 更新到新版
   「關於」→「檢查更新」；有新版時先解鎖，再按「下載更新」。
   接著關閉繫族，雙擊同一個資料夾裡的「套用更新.bat」。族譜資料完全不會被動到。
   ・繫族還開著的話，它會請你先關閉並等一下（約 30 秒）。
   ・舊版會保留成「繫族-舊版.exe」。新版有問題時，把新的 繫族.exe 改名或刪掉，
     再把「繫族-舊版.exe」改回「繫族.exe」就能用回舊版。
   ・出現「改名失敗、所有檔案都沒有變動」：多半是防毒軟體正在檢查，稍後再雙擊一次即可。
   ・資料夾名稱裡有前後都是 % 的字樣（例如 %OS%）時，程式會請你先把資料夾改名、拿掉 % 再下載。
