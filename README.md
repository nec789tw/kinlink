# 繫族 KinLink ｜ 離線族譜與祭祖通知系統

> 輕量、地端、零網路依賴的家族維繫工具。插上隨身碟、點開即用、更新資料庫——適合宗親會、家族長輩在無網路環境下查族譜、算稱謂、印通知。

任何漢人家族／宗親會皆可使用，非專屬單一姓氏。

## 為什麼做這個

- 傳統族譜厚重、難隨身查閱。
- 年輕一輩看不懂複雜親屬稱謂。
- 每年掃墓祭祖要手工做通知函、寄信標籤、聯絡名冊、牌位與穴位表——格式年年重做。
- 管理人員會改選，系統必須能讓非工程師接手：**插隨身碟 → 點開 → 操作 → 安全備份**。

## 核心功能

- **族譜管理**：樹狀圖（全族總覽／以一人為中心的本支家系）與可逐層展開的列表兩種檢視；人物資料含字號、世代、房頭、生卒（國曆＋族譜原文雙軌）、聯絡、安葬資訊、備註。
- **稱謂計算器**：選兩個人，自動算雙向稱謂（含姻親、母系、過繼）；長幼判不出時以「族親」相稱，不硬湊。
- **祭祖活動與通知**：國曆或農曆活動（農曆會檢查日期存不存在、顯示對應國曆）；替每位族親產生個人化通知文字（可帶姓名，以及對祭祀先人的稱謂），一鍵複製到剪貼簿，用自己的手機轉傳。
- **列印／輸出**：掃墓通知單（雙面合併寄送）、信封片頭、通知名單、全家族表、直系族譜表、牌位姓名表、穴排位圖、開會通知，共用一份樣式表、風格統一；用瀏覽器原生「列印／另存 PDF」，零額外套件。另附版式示範範本、操作手冊與交接單，見 [`列印範本/`](列印範本/)。
- **穴排位（場地格線）**：每個墓域／塔自己畫一張圖，版型有三種：方格（幾列幾欄）、面板（幾塊紅框並排，各塊列數可不同）、階梯（主牌位，一層比一層寬、由右往左直書）。點格子把族親放進去，畫面上看到的就是印出來的樣子；格子稱呼自動套「字號　姓公／名　姓氏」。格子多時可匯出 CSV、用 Excel 照紙上的樣子填好再匯入，名字對得到族譜的自動連上（同名同姓看世代分辨）。不預設任何墓園長相，各家族照自己的實況畫；示範資料三種版型各有一張。
- **編輯鎖**：預設唯讀瀏覽，輸入共用 PIN 才能編輯；掃墓現場可帶筆電讓各房分支當場更新（可限定只改自己那一房）。**不會自動上鎖**，用完請按左下角手動上鎖。
- **備份與還原**：一鍵備份、每次開啟與每次解鎖自動備份，全部存在程式旁的 `backups` 資料夾；還原前自動先備份現況。

## 設計取向

- **完全離線**：不連外網、不依賴第三方通訊軟體；只有使用者按「檢查更新」時才連 GitHub。
- **隨身碟即用**：打包為免安裝單一執行檔（內嵌 SQLite 與內建伺服器），不使用 Docker。
- **不過度開發**：能用標準庫／瀏覽器原生功能就不加相依套件（執行期第三方套件只有 pywebview 與 borax）。

完整規格與資料庫說明見 [`docs/規格.md`](docs/規格.md)；工程架構見 [`docs/架構設計.md`](docs/架構設計.md)。

## 快速開始

三種方式，由簡到難：

1. **直接用（給家族總幹事）**：到 [Releases](https://github.com/nec789tw/kinlink/releases) 下載最新的 `kinlink-vX.Y.Z-win-x64.zip`，在 zip 上按右鍵「全部解壓縮」到隨身碟、桌面或任一資料夾（不要放進 `C:\Program Files`，也不要在 zip 裡直接點開），雙擊 `繫族.exe`。第一次 Windows 會跳「已保護您的電腦」：按「其他資訊」→「仍要執行」，因為程式未購買數位簽章；zip 內附 `先看我.txt`。
   第一次開會載入虛構示範資料：點左下角「瀏覽模式」輸入 PIN（出廠 `0000`）解鎖，到「設定」按「清空示範資料」，再匯入自家 CSV。資料庫 `繫族.db` 在 exe 旁邊、備份在旁邊的 `backups` 資料夾，整個資料夾就是全部。詳細步驟見程式內左邊選單「關於 → 開啟手冊」。
2. **從原始碼跑（工程師）**：Python 3.10 以上，`pip install -r requirements.txt` 後 `python app.py`（Windows 可雙擊 `工程師用-原始碼試跑.bat`；`python server.py` 則只起後端並開預設瀏覽器）。原始碼模式讀寫的是專案資料夾裡的開發用 `繫族.db`。沒有 WebView2 時自動退回預設瀏覽器。
3. **自己打包 exe**：需要 64 位元的 Python 3.10～3.13（建議 3.12；3.14 不行，但可以並存）。雙擊 `build_exe.bat`——自動挑支援的 Python（找不到時印中文說明）、建 `build_venv\`、依 `constraints.txt` 鎖版本安裝、跑完全部測試才打包（測試只在維護者電腦上，公開原始碼不附；自己打包時結尾會註明這次沒有測試把關）、打完實際啟動 exe 自我檢查（`--selftest`），結尾列出這次被 SKIP 的測試。產物在 `dist\`：`繫族.exe` 與發佈用的 `kinlink-vX.Y.Z-win-x64.zip`／`.exe`（版本號取自 `VERSION` 檔）。

只想先看畫面：用瀏覽器直接開 [`webview/index.html`](webview/index.html)，會以展示模式運作（虛構示範資料，不存檔）。詳細步驟、測試與常見問題見 [`docs/執行與打包.md`](docs/執行與打包.md)。

## 家族故事｜緣起與致謝

楊士芳（1826–1903），譜名文梓，字蘭如，號芸堂，噶瑪蘭（今宜蘭）人——整個清代，噶瑪蘭只出了他這一位進士。
據本族族譜，他是楊家第十四世、三房，道光六年十二月初八日生；配戴氏、吳氏、曾氏，育有三子五女。
明治三十六年（1903）一月十日卒（農曆光緒二十八年十二月十二日）。

**跛了腳，才拿起書本。** 楊家原在溪南的清水溝柯仔林（今三星、冬山交界）務農，他就在這裡出生。道光二十四年（1844）家中遭襲，
母親罹難、父親重傷，各房兄弟從此分居各地，三房搬到擺厘——擺厘就是今天宜蘭市的進士里，進士里、進士路都是為了紀念他而命名。他十七歲才進私塾，旋即輟學；
後來腿傷不能下田，家人只好讓他回去讀書——這一讀，讀出了噶瑪蘭唯一的進士。

**四十三歲，金榜題名。** 同治元年（1862）中舉；同治七年（1868）赴京會試，以四十三歲之齡中戊辰科三甲第一百一十八名進士，
欽點浙江即用知縣。隔年父親過世（族譜記為同治八年），他依禮丁憂，沒有到浙江上任——從此不再出仕，把一身學問都留給了宜蘭。

**為鄭成功請祠。** 同治十三年（1874）牡丹社事件後，欽差大臣沈葆楨來臺。「臺灣府進士楊士芳」等人稟請為鄭成功追諡建祠，
沈葆楨據稟上奏；光緒元年（1875）正月朝廷准奏，在臺灣府城建立專祠、追諡「忠節」，同年八月落成——
就是今天臺南的延平郡王祠。

**回到宜蘭教書。** 同治八年（1869）他倡建宜蘭孔廟，光緒元年（1875）應聘為仰山書院院長，獎掖後進；
光緒十一年（1885）在宜蘭城內建宅，「楊士芳進士第」廳堂至今仍在。

**碧血丹心望曉霞。** 乙未（1895）割臺，他選擇留下。光緒二十五年（1899）與李望洋等士紳倡建碧霞宮，
主祀精忠報國的岳飛，宮名取「碧血丹心望曉霞」——在日本統治下，把對故國的心意藏進廟名裡。
晚年他在宮中鸞堂擔任「總理堂講事」，扶鸞刊印善書、勸化鄉里。日治初期出任宜蘭廳參事，明治三十年（1897）獲頒紳章。

**今日。** 民國八十三年（1994），碧霞宮傳出要拆舊廟改建，宜蘭縣政府（時任縣長游錫堃）決定保存舊廟，
把宮旁原為臺電宿舍的一帶規劃成彰顯楊士芳精神的紀念林園；建築師黃聲遠團隊自 1997 年起參與規劃，
「楊士芳紀念林園」2003 年完工，2004 年 3 月 15 日由時任行政院長游錫堃主持啟用，成為宜蘭舊城裡的公共空間。
不遠處的進士第，廳堂仍在。

後裔今分大房、二房、三房。族譜自第十一世起算，已續修至第二十二世，錄有上千位族人。每年清明各房循舊例合祭——通知一戶戶寄、名冊一年年重抄、穴位圖照著舊表手畫，而總幹事還會改選。

這套系統就是為了這件事而寫：讓不懂程式的接任者插上隨身碟就能查族譜、算稱謂、印通知，並安穩交給下一任。由「宜蘭楊士芳進士文化發展協會（楊士芳進士家族）」發起，現以 [MIT](LICENSE) 開源，供所有家族／宗親會自由使用——因為每個家族都有同樣的難處。

家族史料以本會考訂為準：生年月日、家庭與父母卒年依本族族譜，生平年份依本會年表；
卒年月日依《臺灣日日新報》（1903）與蘭陽博物館考訂；其餘事蹟整理自公開資料。

**特別致謝**：前立法院長游錫堃先生、宜蘭縣政府文化局。

## 隱私（重要）

- **絕不要把真實家族資料 commit 進公開 repo。** 真實姓名、地址、電話、生卒一旦上傳便可能被永久快取。
- 本專案 [`.gitignore`](.gitignore) 已預設排除：私有資料夾、`*.db`、`/backups/`、匯出的 `*.csv`、原始族譜檔。
- 公開的列印樣板與專案內示範資料一律為虛構，與真實族人無關。自家真實資料請保留於本機，放在 gitignore 的私有夾或私人 repo，不納入公開 repo。
